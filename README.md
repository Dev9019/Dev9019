### [CareerPilot AI](https://github.com/Dev9019/CareerPilot-AI)

My capstone project: an AI-powered Resume Analyzer and Career Assistant built with FastAPI, Ollama, and Llama 3.2.

CareerPilot AI allows users to upload PDF resumes and receive intelligent feedback, including:

- Resume score
- Professional summary
- Strengths detection
- Missing skills identification
- Resume improvement suggestions

**Tech Stack:** Python, FastAPI, Ollama, Llama 3.2, PyMuPDF, JavaScript, HTML, CSS, and Uvicorn.

**Live Demo:** [career-pilot-ai-gray-phi.vercel.app](https://career-pilot-ai-gray-phi.vercel.app)
